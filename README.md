### Various small Python projects to hone in on the fundamental practices of Python programming.

** Blackjack: ** A game where the user plays against the computer and needs to get as close to 21 points without going over and without the computer getting higher than the user.

** Blind Auction: ** A tool where multiple people place a bid privately and later the person that bid the highest wins the auction.

** Caesar Cipher: ** A tool to encrypt and decrypt plain text using the Caesar cipher.

** Calculator: ** A tool to do basic calcualtions between 2 numbers.

** Hangman: ** A game where the user guesses what the randomly selected word is before failing.

** Higher or Lower Game: ** A game where the user must guess out of 2 different Instagram accounts, which one has the higher follower count.

** Number Guessing Game: ** A game where the user needs to guess what number was randomly selected whilst getting hints for help.
